From commit to live in four steps

  1. Step 1

    Git push

    You push to the main branch on GitHub.

  2. Step 2

    Webhook fires

    GitHub calls Jenkins, which starts the pipeline.

  3. Step 3

    Terraform apply

    EC2, security group and NGINX are created or confirmed.

  4. Step 4

    Site updated

    Website files are copied and NGINX reloads.
